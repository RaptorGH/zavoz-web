Политика конфиденциальности Zavoz

Zavoz — личный закрытый сервис для просмотра переписки Telegram-бота. Вход в сервис доступен только приглашённым пользователям.

Какие данные используются

При входе через Google или GitHub сервис получает только адрес электронной почты и имя вашего аккаунта (область доступа openid, email, profile). Эти данные нужны только для того, чтобы определить, есть ли у вас доступ.

Как данные хранятся и используются

Данные хранятся в базе Supabase проекта Zavoz и не передаются третьим лицам. Они не используются для рекламы и не продаются.

Удаление данных

Чтобы удалить свои данные или отозвать доступ, напишите владельцу сервиса. Доступ также можно отозвать в настройках вашего аккаунта Google или GitHub.
